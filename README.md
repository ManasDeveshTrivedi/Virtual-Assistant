# Virtual-Assistant
## Virtual Assistant (MERN Stack) 

An AI-powered Virtual Assistant web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). The assistant allows users to interact through queries and receive intelligent responses in real time.

---

## Clone and Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/ManasDeveshTrivedi/Virtual-Assistant.git
```

### 2. Navigate into the project directory

```bash
cd Virtual-Assistant
```

### 3. Install dependencies

Install backend dependencies:

```bash
cd backend
npm install
```

Install frontend dependencies:

```bash
cd ../frontend
npm install
```

### 4. Setup environment variables

Create a `.env` file in the **backend** folder and add the required environment variables such as:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_api_key
```

### 5. Run the project

Start backend:

```bash
cd backend
npm start
```

Start frontend:

```bash
cd frontend
npm run dev
```
